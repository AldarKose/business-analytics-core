# Business Analytics Core

Универсальное серверное ядро для внешней аналитики по данным учетных систем.

## Назначение

Ядро предназначено для:

- приема данных из 1С и других учетных систем;
- хранения данных в PostgreSQL;
- расчета аналитических витрин;
- построения модулей производственной, закупочной, продажной и AI-аналитики.

## Состав

- PostgreSQL — аналитическая база данных;
- FastAPI — API-сервис;
- Nginx — внешний HTTP-прокси;
- Docker Compose — установка на сервере;
- modules/production — заготовка модуля производственной аналитики.

## Быстрый запуск

1. Скопировать `.env.example` в `.env`:

```bash
cp .env.example .env
```

2. Изменить пароли и ключ API в `.env`.

3. Запустить сервер:

```bash
docker compose up -d --build
```

4. Проверить состояние API:

```bash
curl http://localhost/health
```

Ожидаемый ответ:

```json
{"status":"ok"}
```

5. Проверить защищенный метод:

```bash
curl -H "X-API-Key: change_me_api_key" http://localhost/v1/secure-health
```

## Первые сущности производственного модуля

- products;
- sales_documents;
- production_orders;
- operation_plan;
- operation_fact;
- material_plan;
- material_fact;
- sync_logs.

- сделки;

- заказы покупателей;
- заказы поставщикам;
- заказы на производство;
- завершенные операции;
- сдельные наряды;
- выпуск продукции;
- УПД/реализации;
- банк/оплаты;
- табель сотрудников.
