# Клиентская конфигурация: ИндМет

Клиент: Компания «ИндМет»

Назначение:
- план-фактный анализ производства;
- анализ прибыли, выручки и трудозатрат;
- анализ переделок;
- производственная аналитика;
- подготовка основы для AI-ассистентов.

В репозиторий не добавлять:
- базы 1С;
- выгрузки клиента;
- Excel-расчёты клиента;
- реальные документы;
- пароли и ключи доступа;
- .env-файлы.
