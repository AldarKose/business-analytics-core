# Коннектор 1С

В этой папке будет храниться обработка или расширение 1С для выгрузки данных во внешний аналитический сервер.

Базовый сценарий обмена:

1. 1С формирует JSON по нужной сущности.
2. 1С отправляет данные в FastAPI методом POST.
3. FastAPI валидирует данные и записывает их в PostgreSQL.
4. Результат загрузки фиксируется в sync_logs.
